## What it does

Scam With Your Friends is a game where you play as a scammer trying to con your friends out of money. The game is designed to be frustrating and time-consuming, with a lot of grinding and repetitive tasks. The main frustration points are the time limit, the need to gather information, and the difficulty of actually scamming your friends.

The obvious brute-force option of just spamming your friends with messages is usually the wrong pick because it can get you caught and lead to real-life consequences. Instead, the trainer provides options that allow you to skip the time limit, gather information instantly, and make your scams more convincing without actually doing the work.

## Features

| Option | Hotkey | What it does |
|---|---|---|
| Unlock all money | `F1` | Instantly unlocks all the money in the game |
| Infinite time | `F2` | Removes the time limit and allows you to take as long as you want |
| Skip cutscenes | `F3` | Skips all the cutscenes and gets you straight to the action |
| Information multiplier | slider | `1x`–`50x`, default `3x` — multiplies the amount of information you gather |
| Scam success rate | slider | `0%`–`100%` — the softer alternative to the infinite time option |
| Unlock all scams | `F4` | Unlocks all the scams in the game |
| Skip gathering | `F5` | Skips the gathering phase and goes straight to the scam |
| Save progress | — | Saves your progress and allows you to continue later |
| Unlock all achievements | — | Unlocks all the achievements in the game |
| Free camera | `F10` | Detach from the character and move freely |
| Hide HUD | `F11` | Hides the HUD for screenshots |
| Field of view | slider | `60`–`130 deg` |

<sub>Tags — **`bypass`**: removes the work the game is built around · **`spoiler`**: reveals story early · **`save`**: writes persistent data · **`comfort`**: accessibility, changes nothing. Use at most three. Anything tagged `bypass` or `spoiler` ships off.</sub>

## Hotkeys

`Insert` opens the menu · `End` resets everything · `F1`–`F12` as above, all rebindable · arrow keys and `Enter` navigate without a mouse

> [!TIP]
> For the best experience, set the information multiplier to `10x` and the scam success rate to `100%`. This will allow you to gather information quickly and make your scams more convincing without actually doing the work. The time limit will still be in place, but you can take your time to plan your scams.

> [!WARNING]
> The skip gathering option will remove the most frustrating part of the game, but it will also make the game much easier. If you're looking for a challenge, it's best to avoid this option.

## FAQ

<details>
<summary>Will I get banned?</summary>
No. Single-player only, no anti-cheat, no ranked mode. Achievements unlock locally unless you block them in the menu.
</details>

<details>
<summary>How do I unlock all the money?</summary>
Just press `F1` and all the money will be unlocked. It's that simple!
</details>

<details>
<summary>How do I skip the time limit?</summary>
Press `F2` and the time limit will be removed. You can now take as long as you want to complete your scams.
</details>

<details>
<summary>Does it work on Steam Deck or Linux?</summary>
No. Windows only. Proton changes how the game's memory is laid out and this build does not handle that.
</details>

<details>
<summary>Windows Defender flagged the download.</summary>
Trainers read and write another process's memory, which is what a lot of malware also does, so heuristic scanners flag them on principle. Every release ships with a SHA256 checksum and full source. Add an exclusion if you are comfortable with that — and if you would rather not, don't. That is a reasonable call.
</details>

<details>
<summary>Options stopped working after an update.</summary>
Patches move memory offsets and options fail independently, so some will keep working. Check the Releases page for a build matching your game version.
</details>

## Troubleshooting

| Symptom | Fix |
|---|---|
| Nothing happens on `Insert` | Another overlay grabbed the key — Steam, Discord or RTSS. Rebind the menu key. |
| "Process not found" | The game must be running with a save loaded. Launch it first, then attach. |
| Some options do nothing | That memory allocates only in a scam. Get there first, then toggle. |
| Unlocks vanished after a patch | A persistent write was invalidated. Restore a backup from before the update. |
| Game-specific issue | If it is a known game bug rather than yours, say so and point at the developer's notes. |
